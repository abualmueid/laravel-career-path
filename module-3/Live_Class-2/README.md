# Form Handling with PHP - Simple User Registration System 

This is a very simple user registration system in php. This is a project to learn form handling in php.

# Features
1. Welcome page
2. Registration page
3. Login page
4. Dashboard page

# Installation
1. Clone the repository 
    ```
    git clone https://github.com/abualmueid/laravel-career-path.git 
    cd laravel-career-path
    git checkout module-3
    ``` 

2. Run web and database server in your localhost.
3. Run `index.php` file. 

# Usage 
1. User can register using their name, email address and password.
2. User can log in using their email address and password.
3. User can see their profile pic and welcome message after log in to his/her dashboard.
